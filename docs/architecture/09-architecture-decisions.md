# 9. Architecture decisions

The significant architectural decisions of this repository, one ADR each in `docs/adr/`, written with the full template of [MADR 4.0.0](https://github.com/adr/madr/releases/tag/4.0.0), as the framework's [CONVENTIONS](https://github.com/fabrizioiacobucci/foss-docs-made-simple/blob/v0.2.0/framework/CONVENTIONS.md#adrs) asks. The status and the date of each decision are at the top of its ADR.

The decisions made before this repository adopted the framework, on 2026-10-26, have no ADR. Each decision made since then has its ADR, written when the decision is made, as the [DEFINITION-OF-DONE](../DEFINITION-OF-DONE.md#changes) requires.
